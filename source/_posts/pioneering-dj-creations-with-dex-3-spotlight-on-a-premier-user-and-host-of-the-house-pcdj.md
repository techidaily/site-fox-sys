## Pioneering DJ Creations with DEX 3: Spotlight on a Premier User and Host of the House – PCDJ

**Each month we highlight one PCDJ [DJ Software](https://tools.techidaily.com/pcdj/products/) or [Karaoke Software](https://tools.techidaily.com/pcdj/products/) user, and their business. This month meet DJ Adam Lawson of Hopatcong New Jersey USA, a new DEX 3 DJ software user.**

_**PCDJ:**_ **_Why did you choose PCDJ DEX 3 for your Mobile DJ business?_**

_**A.L.:**_ My company does both karaoke and DJ gigs we often start out the karaoke gigs by DJing for a while. Dex 3 is the only all in one solution out there it allows me to seamlessly transition between DJing and Karaoke. Running one software program also eliminates the issues of conflicting audio settings and saves on CPU usage.

![](https://i1.wp.com/www.pcdj.com/wp-content/uploads/2014/09/adam21.jpg?resize=249%2C249&ssl=1 "adam2")

_**PCDJ:**_ _**What tip would you give to other DJs?**_

_**A.L.:**_ Sometimes a singer will want to sing along with the original track but have the lyrics on the screen DEX 3 allows this by loading the Karaoke version and the original version simultaneously. The file system on DEX is awesome and allows you to import your iTunes library or create folders from your hard drives within the program. We have over 25,000 tunes and 35,000 karaoke files and the file manager has worked flawlessly.
